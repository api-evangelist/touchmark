# Touchmark

> Touchmark is solving AI pricing: instead of charging per token regardless of quality, it prices AI by the quality, efficiency, and value of the output. Applications emit the events they already produce (model outputs, tool calls, code diffs) and Touchmark returns a quality-adjusted fair price for each one on a separate valuation stream. Y Combinator Summer 2026; TypeScript SDK in private beta.

Generated by API Evangelist from the provider's public docs on 2026-07-21 (Touchmark publishes no llms.txt of its own; docs.touchmark.ai/llms.txt is 404 and touchmark.ai/llms.txt is an SPA fallback).

## Docs

- [SDK overview](https://docs.touchmark.ai/sdk/overview): What the Touchmark SDK is, and the mental model - Session, Event, Valuation, and the fire-and-forget emit rule.
- [Quickstart](https://docs.touchmark.ai/sdk/quickstart): Install @touchmark/sdk, open a session, emit events, consume valuations, handle session expiry (~10 minutes).
- [API reference](https://docs.touchmark.ai/sdk/reference): Every option, method, and type - Touchmark client, session.start/emit/end/streamValuations, Valuation, Payload, EventType, TouchmarkError, degraded mode, money model.
- [Errors & recovery](https://docs.touchmark.ai/sdk/errors-and-recovery): The closed set of seven error codes and exactly what to do about each.

## APIs

- [Touchmark Sessions API](https://api.touchmark.ai): Default base_url of the SDK; HTTP transport over a protobuf/gRPC wire contract (proto/touchmark/v1/session.proto). Auth: Authorization: Bearer <api_key>. No public OpenAPI.
